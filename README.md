# HR Analytics Dashboard | Power BI

## Project Overview
This project analyzes HR data to understand employee demographics, workforce distribution, and employee attrition.

## Tools Used
- Microsoft Power BI
- DAX
- Data Visualization

## Key Analysis
- Total Employee Count
- Employee Attrition Rate
- Department-wise Employee Analysis
- Salary Distribution
- Employee Demographics

## Objective
To turn HR data into meaningful insights that support better workforce planning and data-driven HR decisions.
